## 缘起

佛经从第一次结集至今，历朝历代、东西国别，都有整理与翻译。本站把这些散落在各藏各本中的典籍，按经、律、论与近现代著述分门别类，转为 Markdown 格式，供人逐篇翻阅。

大藏经浩瀚，起于一枚巴梨陀、共诵之结集，终于宋元明清数千卷的雕版、印本。其量之大，非一目可尽；其义之深，非一读可穷。阅藏经取三事为纲：其一，以统计为骨，让读者先见其大体；其二，以原典为肉，逐篇录入正文，可读可校；其三，以目录学与近代教史为睛，为旧典开出新的读法。

## 内容来源

正文依 **CBETA 中華電子佛典協會** 整理本录入，逐档元数据——题名、题署、藏经编号、册次、卷数、字数——取自 CBETA 大藏经数据库。每档一篇，以 Markdown 承载。

- 藏经编号采用国际通行写法，如 T0235（大正藏第 8 册第 235 号）、X1565（卍续藏第 1565 号）。
- 繁体底本保持原貌，不作简化，以便按原典核对。
- 部分经典另附本站「义理提要」，以导读补其法义。

除大正藏主干外，本站并收《卍续藏》《嘉兴藏》系统诸本、藏外佛教文献、北朝石刻拓片、房山石经、国家图书馆善本佛典，以及南传与近代撰述，构成一部可互补参校的阅读本。**各藏经来源的篇数、卷数与字数分布**，见「藏经概览」页。

## 结构

全站分为三大固定分类与若干专题：

- **大藏经** —— 全藏经律论注疏（二十八部类），页内附部类分布与各部类首篇导览。
- **禅宗** —— 诸宗部为骨干，跨部类收录语录、灯录、坛经、传心法要等。
- **近代著作** —— 赵朴初、汤用彤、印顺、黄夏年、丁福保等近现代佛学家的读经笔记与通史断代。

**专题**则不拘部类，而以宗派、门类为线索横跨全藏，如禅宗、净土宗、天台宗、华严宗、律宗、唯识宗、中观三论、目录学等，择取一组可连缀而读之典籍。

## 体例

每篇正文皆依统一格式：**标题**、**著者·译者**、**藏经编号与藏名**、**册次与部类**、**卷数与字数**、**正文**。正文以 Markdown 书写，目录层级与滚动高亮由构建期与浏览器共同完成。

正文页面为宽度 100% 的上—中—下结构：篇首（面包屑 → 标题 → 著者 → meta 信息带 → 字号／全屏／链接／篇目）→ 正文纸面 → 篇末。正文纸面与页面背景保持约两成的视觉差，读来如案上一纸。

## 收录原则

1. **以原典为准**：正文一字未改，仅作断句与标点整理；不同版本字句有出入者，以底本为准并注明。
2. **存疑待考**：疑似部、古逸部之属，一仍其旧，标明存疑，不作径改。
3. **导读从简**：本站导读只补法义与读法，不代原典立说；近代著述受篇幅所限，以提要与节要呈现其要义。
4. **可检索可参校**：全站索引随正文生成，可按篇名、著者、藏经编号、部类检索；同名异本并存，编号各异，便于参校。

## 技术

本站由 [Astro](https://astro.build/) 构建，托管于 GitHub Pages；内容以 Markdown 内容集合（Content Collections）与 TypeScript 数据模块维护，静态输出，无追踪脚本。

- **版式**：Tailwind CSS 设计令牌驱动「墨夜 / 素白」双主题，阅读字号可调。
- **交互**：目录滚动监听、阅读进度、全屏阅读、篇目即时检索，均为原生 JavaScript，无前端框架运行时。
- **无障碍**：语义化标签、跳转链接、键盘可达的目录与检索控件、动效降级。
- **数据**：所有统计数字由导入器自语料实算，随语料更新自动刷新，不作手工誊写。
