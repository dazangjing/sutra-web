# 繁体转简体（`simplify`）

本文件说明 `main.py simplify` 的转换规则、字表来源与实测结果。

## 1. 规则

| 情形 | 处理 | 例 |
| --- | --- | --- |
| 繁体字只有**一个**简体对应 | 转成该简体字 | `後` → `后`；`譯` → `译`；`靈` → `灵` |
| 繁体字**没有**对应简体（异体／罕用字） | 保留繁体原字 | `㑮`、`𫝈` 之类扩展区字符 |
| 繁体字**对应多个**简体，且其中**只有一个常用简体**（其余为罕见异体字） | 转成该常用简体 | `開` → `开`；`願` → `愿`；`線` → `线`；`麵` → `面` |
| 繁体字**语义真歧义** | 保留繁体原字 | `乾` → 干／乾；`於` → 于／於；`覆` → 覆／复 |

原则：**只保留真正需要依上下文判断的字；能确定的都转**。
逐字一对一替换不改变任何字词长度，故 `stats.text_length` 等统计栏位
在转换前后完全一致。

### 1.1 「语义真歧义」的判准

多值列举（OpenCC `TSCharacters.txt` 的一行对应多个简体）分两类处理：

1. **繁体字本身也在列举之中** → 该字在简体语境中**仍可保留**，
   须依上下文判断，故**保留繁体**：
   - `乾`（乾坤）／`於`（姓氏）／`覆`（覆盖）／`阪`（大阪）／`彷`（彷徨）
     ／`徵`（徵召）／`藉`（狼藉）／`祇`（祇洹）／`衹`／`薹`／`夥`／`牴`
     ／`剋`／`瞭`／`麽`
2. **列举中有两个以上常用简体** → 目标不同，语义有别，故**保留繁体**：
   - `畫`（画／划）、`餘`（余／馀）、`麼`（么／麽）、`鍾`（钟／锺）、
     `諮`（咨／谘）、`鍊`（炼／链）、`鉅`（巨／钜）、`鏇`（旋／镟）、
     `瀋`（沈／渖）

其余情况（列举中只有一个常用简体，其余是罕见异体字，如 `開` → 开／𫔭）
并非语义歧义，**予以转换**。

「常用简体」的判准：**GB2312 汉字集 ∪ 单一对应表的目标字**。

## 3. 转换范围

JSON 内**所有字符串值**皆套用转换：书目（`work`）、标题、卷次索引、档头
（`header`）、注释索引（`notes`）、正文（`body`／`back` 节点树）、顶层
`text` 全文、统计文字等。

例外（刻意不变）：

- `xml_path`、`path` —— 指向**来源**语料（`xml-p5`）的路径，不随输出库改名；
- `lang`（`zh-Hant`）—— 语言标记维持原样。

### 3.1 目录名一并转为简体

`catalog.json` 的 `canons[*].directory`），使档内记载与实际目录名一致。
档案**文件名**皆为 ASCII（如 `T14n0574.json`），无须处理。

## 5. 用法

```bash
python3 main.py simplify --src /Users/jk/workspace/codebase/sutra_json \
                         --dst /Users/jk/workspace/codebase/sutra_md_zh
```

选项：`--src`（来源目录）、`--dst`（输出目录，必填）、`--jobs`（平行行程）、
`--map`（字表路径）、`--top`（残留字统计列印笔数）、
`--no-rename-dirs`（不改名藏经目录）。
